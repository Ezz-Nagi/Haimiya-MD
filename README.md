## ✨ Instalación en Termux

<div align="center">
  <a href="https://github.com/termux/termux-app">
    <img src="https://img.shields.io/badge/TERMUX-DESCARGAR-222222?style=for-the-badge&logo=android&logoColor=white">
  </a>
</div>

<details>
  <summary><b> ✎ Haz clic para ver los comandos de instalación</b></summary>

  **1. Preparar el almacenamiento**

  ```bash
  termux-setup-storage
  ```

  **2. Instalar los paquetes necesarios**

  ```bash
  pkg update && pkg upgrade -y
  pkg install -y git nodejs-lts ffmpeg imagemagick
  ```

  **3. Descargar HAIMIYA**

  ```bash
  git clone https://github.com/Ezz-Nagi/Haimiya-MD.git
  ```

  **4. Entrar en la carpeta**

  ```bash
  cd Haimiya-MD
  ```

  **5. Instalar dependencias**

  ```bash
  npm install
  ```

  **6. Iniciar el bot**

  ```bash
  npm start
  ```

  **Para volver a iniciar HAIMIYA:**

  ```bash
  cd ~/Haimiya-MD
  npm start
  ```

</details>
